Harnais de test — bridge window.livechatOverlay

Charge ./bridge.js en script classique, exerce les 13 méthodes et affiche chaque appel. Ouvrable directement en file:// (mode mock, aucun réseau), sans bundler ni dépendance.

1. Méthodes de commande (invoke / send)

Les payloads sont éditables en JSON. Les méthodes send sont fire-and-forget côté Electron.

2. Abonnements aux événements main → renderer

En mode mock, aucun backend n'émet : utiliser les boutons ci-dessous (window.__bridgeMockEmit) pour simuler overlay://play, overlay://stop et overlay://settings.

3. Journal des appels (window.__bridgeCalls)

# Méthode Statut Arguments / résultat Horodatage
Mode mock : getConfig renvoie une config neutre (serverUrl: null), consumePairing renvoie { ok: true } sans réseau, getMediaBindings renvoie { bindings: {} }, les rapports sont des no-op. Après rendererReady, le bridge simule l'envoi de overlay://settings. Aucun secret n'est journalisé : les clés contenant token, code, sig sont masquées (***).
